AsterDesk portable

Extract the entire AsterDesk folder to a writable local directory. Run AsterDesk.exe.
The runtime and current complete workshop catalog are included. No Python
installation or initial workshop connection is needed. Run as administrator when
the target requires it. System input requires the game to stay in the foreground.

Settings, imported teams, cached packages and logs live in data/. Preserve data/
when extracting a newer version. Client Settings provides the global keyboard and
mouse input switch, old configuration import and independent release downloads.

Only aster-vMAJOR.MINOR.PATCH releases from jawwe/ok-wuthering-waves are used.
Downloads are checksum-verified. Close the client before extracting an update.

Offline package check: AsterDesk.exe --self-check
The result is saved to data/self-check.json. This check sends no game input.

Licenses and upstream attribution are preserved in LICENSE.txt and app/.
